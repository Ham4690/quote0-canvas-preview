windowData JSON を貼ると、実機画面サイズ(296×152px、Image API 仕様記載値)の枠内でレンダリングする。 赤点線は画面の境界。境界をまたいで描画される要素があれば、それが「見切れ」の原因。 tw(Tailwind 風ユーティリティ)は主要な flex / spacing 系のみ簡易解釈、props.style は値をそのまま適用する。

入力 — CanvasPayload / windowData

貼る内容: Send に渡す実際の CanvasPayload({"windowData":{...}} を含む全体)でも、windowData 単体でも、default 配列単体でも認識する。
